# 乐淘优品 · 电商经营数据分析

基于 **2025-07 至 2026-06**（共 12 个月）运营数据的电商经营分析项目，覆盖经营总览、用户行为、退款异常与商品效率四大主题，输出交互式看板与分析报告。

## 仓库内容

| 文件 | 说明 |
|------|------|
| [`dashboard_all.html`](./dashboard_all.html) | 四页合一交互看板（深色科技风，ECharts） |
| [`乐淘优品经营数据分析报告.pdf`](./乐淘优品经营数据分析报告.pdf) | 经营数据分析报告（PDF） |

## 看板说明

用浏览器直接打开 `dashboard_all.html` 即可查看（建议 Chrome / Edge）。顶部可切换四个主题：

1. **总览经营** — 平台 GMV、订单、用户等核心经营指标与趋势  
2. **用户行为** — 浏览 / 加购 / 收藏 / 购买转化漏斗与行为洞察  
3. **退款异常** — 退款结构、异常订单与风险信号  
4. **商品库存** — 品类 / 商品效率、库存与动销表现  

数据范围说明（量级）：

- 用户约 1 万、商品约 800  
- 订单明细约 11 万+，用户行为日志约 61 万+  
- 含支付方式、会员等级、城市线级等维度
